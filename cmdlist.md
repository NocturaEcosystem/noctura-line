# List of commands

```sh
noctura start-server # starts nyx-server, returns "already started" if an instance already exists

noctura exists       # checks if the system has noctura tools and uses noctura systems

noctura spawn Lepus  # Spawns the lepus desktop shell. flags include
#                      --MiddleGround, --Widgets, --OSD, --Background
#                      No flags just summons all the layers

noctura spawn Axion  # Spawns the Axion compositor. flags include
#                     --with-no-shell
```
